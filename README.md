# 🚀 AgentAI - 3D Animated Landing Page

[![Netlify Status](https://api.netlify.com/api/v1/badges/ddcc726e-50a4-4161-9747-eb5e0a8877a2/deploy-status)](https://app.netlify.com/projects/peaceful-bienenstitch-ac5997/deploys)

A state-of-the-art, high-velocity 3D animated agency landing page built with **React 19**, **TypeScript**, **Vite**, **Tailwind CSS v4**, and **Motion**.

🌐 **Live Demo:** [https://peaceful-bienenstitch-ac5997.netlify.app/](https://peaceful-bienenstitch-ac5997.netlify.app/)

---

## ✨ Highlights & Features

- **🎥 Cinematic 3D Video Hero:** High-impact background video showcasing AI motion design with an ultra-clean, non-obstructive CTA headline layout.
- **💎 Glassmorphism Navbar:** Sticky transparent navigation bar with dynamic color transitions (`text-black` to `text-white` on hover/active states).
- **🎨 Sleek Dark Aesthetic:** Tailored color system featuring **Flame Red (`#DE3126`)**, **Vibrant Coral (`#FF4E3E`)**, and deep dark pitch-black surfaces (`#000000` / `#0E0E12`).
- **🖼️ High-Res Section Banners:** Custom showcase imagery embedded across all 8 major sections with smooth hover physics.
- **📱 Fully Responsive:** Optimized for ultra-wide monitors, laptops, tablets, and mobile smartphones.
- **⚡ 8 Interactive Sections:**
  1. **Hero Section:** High-velocity headline with background video playback.
  2. **Core Capabilities (Services):** 6 service cards covering Branding, Art Direction, Motion, AI Prototyping, Product Design, and Launch Support.
  3. **Selected Engagements (Works):** Interactive showcase grid of flagship AI & Web3 products.
  4. **Operating Model (Process):** 14-day sprint roadmap breakdown (Discover, Prototype, Validate, Launch).
  5. **Mission & Collective (About):** Core track record stats (230+ projects, 400+ partners).
  6. **Transparent Investment (Pricing):** 3-tier pricing cards with feature checklists and interactive modals.
  7. **Proof of Velocity (Testimonials):** Real founder reviews with metric badges.
  8. **Zero Ambiguity (FAQ & Contact):** Interactive accordion Q&A and active contact form.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/xuanduongdev08/3d-Animation-Landing-Page.git
cd 3d-Animation-Landing-Page
```

### 2. Install dependencies
```bash
npm install --legacy-peer-deps
```

### 3. Run development server
```bash
npx vite
```
Open `http://localhost:3000` in your browser.

### 4. Build for production
```bash
npx vite build
```
